# 📺 Projeto Landing Page - Alura+

## 📌 Descrição do Projeto

Este projeto é uma **landing page responsiva** inspirada na plataforma Alura+, desenvolvida com **HTML5 e CSS3**. O objetivo é praticar conceitos de estruturação de páginas, estilização moderna e organização de layout utilizando **CSS Grid e Flexbox**.

A página apresenta um plano de assinatura fictício, destacando benefícios, dispositivos compatíveis e chamadas para ação (CTA), simulando uma página real de vendas.

---

## ⚙️ Funcionalidades

* Layout moderno e responsivo
* Uso de **CSS Grid** para organização principal da página
* Uso de **Flexbox** para alinhamento de elementos
* Botões com efeito **hover (animação de escala e cor)**
* Seções organizadas:

  * Destaque principal (Hero)
  * Benefícios do serviço
  * Apresentação de dispositivos
  * Rodapé com links úteis
* Tipografia personalizada com Google Fonts (Inter)

## 🚀 Como utilizar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/Messihprx/projeto-curso-ub2.git
```

2. Acesse a pasta do projeto:

```bash
cd projeto-curso-ub2
```

3. Abra o arquivo `index.html` no navegador:

* Clique duas vezes no arquivo
  ou
* Use uma extensão como **Live Server** no VS Code
